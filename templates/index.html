Why Rust

Correctness at compile time.

Rust pushes correctness to compile time: strong typing, memory and thread safety, no garbage collector. That fits standards like ISO 26262 and IEC 61508 very well. You catch errors earlier in the V-model, and verification gets cheaper.

{{ }}IEC 61508{{ }}ISO 26262{{ }}IEC 62304
{{ }}Early error detection

Memory and concurrency bugs show up at build time, long before integration testing.

{{ }}Deterministic, safe code

No hidden runtime. Safe Rust cannot cause undefined behavior, as long as the unsafe code below it is sound.

{{ }}Less testing overhead

The compiler rules out whole classes of bugs, so your tests can focus on behavior.

{{ }}Faster integration cycles

Fewer surprises when the parts come together on the target.
