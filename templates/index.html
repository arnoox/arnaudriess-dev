Why Rust

What the Rust compiler finds at build time

The Rust compiler finds memory errors and data races at build time. It does not find logic errors or wrong requirements. ISO 26262 and IEC 61508 recommend methods that find errors early. The Rust compiler does a part of this work on each build.

{{ }}IEC 61508{{ }}ISO 26262{{ }}IEC 62304
{{ }}Memory errors at build time

In safe Rust, the compiler rejects use after free, double free, and data races. These errors appear before the integration test.

{{ }}No hidden runtime

Rust has no garbage collector. Safe Rust cannot cause undefined behavior if the unsafe code below it is sound.

{{ }}Tests for the function

The compiler excludes these error classes. Tests can then look at the function.
